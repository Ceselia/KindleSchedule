# 日历汇总页 测试方法

本文档说明如何在电脑上端到端测试「日历汇总页」（`/calendar`）。

## 一、启动服务

```bash
export PATH="$HOME/node/bin:$PATH"   # 若 node 装在 ~/node
cd /Users/chexinyi/Desktop/project/Kindle/kindle-dashboard
npm install
npm run db:init:local     # 首次：本地 D1 建表
npm run dev               # wrangler dev，默认 http://localhost:8787
```

看到 wrangler 打印 `Ready on http://localhost:8787` 即成功。

> 改 `src/**`/`.html` wrangler 会自动重载；改 `wrangler.toml` 需重启。

页面入口：

- 日历汇总页：http://localhost:8787/calendar
- 单日看板：http://localhost:8787/dashboard
- 添加页：http://localhost:8787/add

## 二、造测试数据

为看清日历效果，建议造「同一天多条 + 跨多天 + 跨月」的数据。三种方式任选：

**方式 A：网页添加页**

打开 `/add`，用一句话或表单添加，例如 `9月20号上午9点 体检  空腹`。

**方式 B：curl 调 API（推荐批量造数据）**

```bash
# 同一天多条（用于验证 +N）
curl -s -X POST localhost:8787/api/schedules -H 'Content-Type: application/json' -d '{"date":"2026-09-20","time":"09:00","title":"体检","note":"空腹"}'
curl -s -X POST localhost:8787/api/schedules -H 'Content-Type: application/json' -d '{"date":"2026-09-20","time":"11:00","title":"取报告"}'
curl -s -X POST localhost:8787/api/schedules -H 'Content-Type: application/json' -d '{"date":"2026-09-20","time":"15:00","title":"买菜"}'
# 其它天
curl -s -X POST localhost:8787/api/schedules -H 'Content-Type: application/json' -d '{"raw":"9月25号 下午3点 开会"}'
# 跨月（下个月）
curl -s -X POST localhost:8787/api/schedules -H 'Content-Type: application/json' -d '{"date":"2026-10-02","time":"10:00","title":"复查"}'
```

**方式 C：模拟微信消息**

```bash
curl -s -X POST localhost:8787/wechat -H 'Content-Type: text/xml' \
  -d '<xml><ToUserName><![CDATA[gh_demo]]></ToUserName><FromUserName><![CDATA[u1]]></FromUserName><CreateTime>1700000000</CreateTime><MsgType><![CDATA[text]]></MsgType><Content><![CDATA[9月28号上午8点 吃药]]></Content></xml>'
```

## 三、验证 API（按月查询）

```bash
curl -s "localhost:8787/api/schedules?month=2026-09"
```

预期：返回 2026-09 整月全部日程（**含已过去的日期**，按日期+时间排序）。切换 `month=2026-10` 应只返回 10 月数据。

## 四、验证日历页面

打开 http://localhost:8787/calendar，逐项检查：

| 检查项 | 预期 |
|--------|------|
| 月历网格 | 顶部显示「2026年9月」，周一为第一列，6×7 网格 |
| 今天标记 | 今天的日期数字为黑底白字药丸 |
| 粗略提醒 | 有日程的格子在数字下显示最多 2 条精简标题（超 6 字截断为 …） |
| +N | 20 号有 3 条 → 显示前 2 条 + 「+1」 |
| 点击展开 | 点 20 号格子 → 进入当天详情，卡片显示 09:00 体检(空腹)/11:00 取报告/15:00 买菜 |
| 返回 | 点「‹ 返回」回到月历 |
| 下一月 | 点 `›` 切到 2026年10月，能看到 10-02 复查 |
| 跨年 | 从 1 月点 `‹` 到上一年 12 月；从 12 月点 `›` 到下一年 1 月，标题年份正确 |
| 空日期 | 点没有日程的格子无反应；非本月补齐格灰底不可点 |

## 五、边界用例

| 用例 | 操作 | 预期 |
|------|------|------|
| 空月份 | 切到无任何日程的月份 | 网格正常显示，全部格子空白，不报错 |
| 全天日程 | 添加不带时间的日程后查看详情 | 卡片时间显示「全天」 |
| 特殊字符标题 | 标题含 `<` `&` | 页面正常转义显示，不破坏结构 |
| 月首/月末对齐 | 观察 1 号所在列、最后一天所在列 | 与周一为首列的排布一致 |

## 六、无回归检查

确认原有页面不受影响：

- `/dashboard` 单日看板左右滑动/箭头切换正常。
- `/add` 两种模式提交正常。
- 解析逻辑（src/parser.js）在 `npm run dev` 下经 POST/微信接口验证正常。
