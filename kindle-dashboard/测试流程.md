## 2. REST API 冒烟测试

```bash
# 配置
curl -s localhost:3000/api/config; echo
# 一句话新增（走解析）
curl -s -X POST localhost:3000/api/schedules -H 'Content-Type: application/json' -d '{"raw":"明天下午3点 张医生复查  带病历"}'; echo
# 结构化新增
curl -s -X POST localhost:3000/api/schedules -H 'Content-Type: application/json' -d '{"date":"2026-09-20","time":"09:00","title":"体检","note":"空腹"}'; echo
# 列表（今日及以后）
curl -s localhost:3000/api/schedules; echo
# 按月
curl -s "localhost:3000/api/schedules?month=2026-09"; echo
# 按天数
curl -s "localhost:3000/api/schedules?days=3"; echo
```

预期：POST 返回 `{"success":true,"schedule":{...}}`；GET 返回按日期+时间排序的数组；`month` 查询含当月过去日期。

## 3. 微信话术测试（模拟公众号回调）

```bash
wx(){ curl -s -X POST localhost:3000/wechat -H 'Content-Type: text/xml' -d "$1"; echo; }
# 关注事件 → 欢迎语
wx '<xml><FromUserName><![CDATA[u1]]></FromUserName><ToUserName><![CDATA[gh]]></ToUserName><MsgType><![CDATA[event]]></MsgType><Event><![CDATA[subscribe]]></Event></xml>'
# 问候/帮助 → 引导话术
wx '<xml><FromUserName><![CDATA[u1]]></FromUserName><ToUserName><![CDATA[gh]]></ToUserName><MsgType><![CDATA[text]]></MsgType><Content><![CDATA[你好]]></Content></xml>'
# 正常创建 → 已为您创建日程「...」
wx '<xml><FromUserName><![CDATA[u1]]></FromUserName><ToUserName><![CDATA[gh]]></ToUserName><MsgType><![CDATA[text]]></MsgType><Content><![CDATA[后天上午9点 量血压  空腹]]></Content></xml>'
# 非文字 → 引导发文字
wx '<xml><FromUserName><![CDATA[u1]]></FromUserName><ToUserName><![CDATA[gh]]></ToUserName><MsgType><![CDATA[voice]]></MsgType></xml>'
```

预期回复 `<Content>`：
- 关注：`您好，我是您的日程小助手～ ...`
- 你好：引导话术
- 正常创建：`已为您创建日程「9月18日 周五 09:00 量血压 空腹」`
- 语音：`我目前只看得懂文字消息哦～ ...`

## 4. 单日看板 /dashboard

浏览器打开 http://localhost:3000/dashboard：

| 检查项 | 预期 |
|--------|------|
| 默认显示 | 顶部显示"今天"+星期+月日，卡片为今天的日程 |
| 无日程 | 显示"今日无日程" |
| 左滑 / 点 → | 切到下一天 |
| 右滑 / 点 ← | 切到上一天（不早于今天） |
| 自动刷新 | 新增日程后 30 秒内自动出现（不想等可刷新） |

## 5. 日历汇总页 /calendar

浏览器打开 http://localhost:3000/calendar：

| 检查项 | 预期 |
|--------|------|
| 月历网格 | 顶部"YYYY年M月"，周一为首列，今天为黑底白字 |
| 粗略提醒 | 有日程的格子显示最多 2 条精简标题（超 4 字省略），多余显示 `+N` |
| 点击展开 | 点某天 → 进入该天详情（大字卡片：时间/标题/备注） |
| 返回 | 点"‹ 返回"回到月历 |
| 切月 | 点 `‹ ›` 切换上下月，支持跨年 |
| 跨天 | 常驻不刷新页面时，过一天自动跳回当前月月历并高亮今天 |

## 6. 端到端典型场景

1. 用第 3 节的"正常创建"模拟发一条微信消息。
2. 打开 `/dashboard`：若是今天/明天等，能看到卡片。
3. 打开 `/calendar`：对应日期格子出现粗略提醒，点开是详情。
4. 说明：这条链路等价于"家人微信发消息 → Kindle 端自动显示"。
