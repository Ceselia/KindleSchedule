# 正式部署（Cloudflare Workers + D1）

本项目后端运行在 Cloudflare Workers，数据存 Cloudflare D1。部署后自带 HTTPS 域名，可直接给微信公众号做回调。

## 一、准备

1. 一个 Cloudflare 账号（免费版即可）。
2. 本地已 `npm install`。
3. 登录 wrangler（会打开浏览器授权）：

```bash
npx wrangler login
```

## 二、创建 D1 数据库并建表

```bash
# 创建数据库，输出里会给出 database_id
npx wrangler d1 create kindle-dashboard
```

把输出的 `database_id` 填进 `wrangler.toml` 的 `[[d1_databases]]` → `database_id`（替换占位符）。然后在远程库建表：

```bash
npm run db:init:remote      # = wrangler d1 execute kindle-dashboard --remote --file=schema.sql
```

## 三、部署 Worker

```bash
npm run deploy              # = wrangler deploy
```

部署成功后会输出 Worker 域名，形如 `https://kindle-dashboard.<子域>.workers.dev`。用它访问：

- 看板：`https://<域名>/dashboard`
- 日历：`https://<域名>/calendar`
- 微信回调：`https://<域名>/wechat`

如需自定义域名，在 Cloudflare 控制台 Workers → 该 Worker → Triggers → Custom Domains 绑定。

## 四、GitHub 自动部署（可选）

把仓库推到 GitHub 后，二选一：

- **控制台连接仓库**：Cloudflare 控制台 → Workers & Pages → 连接 Git 仓库，构建命令填 `npx wrangler deploy`。
- **GitHub Actions**：用 `cloudflare/wrangler-action`，在仓库 Secrets 配 `CLOUDFLARE_API_TOKEN`（含 Workers/D1 编辑权限）：

```yaml
name: deploy
on: { push: { branches: [main] } }
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: cloudflare/wrangler-action@v3
        with:
          apiToken: ${{ secrets.CLOUDFLARE_API_TOKEN }}
```

> 注意：`.wrangler/`、`node_modules/` 已在 `.gitignore`，不会推上去；`wrangler.toml` 里的 `database_id` 会随仓库提交（它不是机密）。

## 五、配置微信公众号

后台「开发 → 基本配置 → 服务器配置」：

| 项 | 值 |
|----|----|
| URL | `https://<worker域名>/wechat` |
| Token | 与 `wrangler.toml` 的 `WECHAT_TOKEN` 一致 |
| EncodingAESKey | 随机生成 |
| 消息加解密方式 | **明文模式** |

提交时微信发 GET 校验签名（Worker 已用 WebCrypto SHA1 校验并返回 echostr）。改了 Token 需重新 `npm run deploy`。

## 六、密钥管理（建议）

Token 若想不写进仓库，可改用 Secret：

```bash
npx wrangler secret put WECHAT_TOKEN     # 按提示输入，覆盖 vars 中的同名值
```

代码里 `env.WECHAT_TOKEN` 会优先取 secret。

## 七、排查

| 现象 | 排查 |
|------|------|
| 部署失败 `database_id` 报错 | 是否已 `wrangler d1 create` 并把 id 填进 wrangler.toml |
| 微信提交「配置失败」 | Worker 是否已部署、URL 是否 `/wechat`、Token 是否一致、是否明文模式 |
| 发消息无回复 | `wrangler tail` 看实时日志；确认明文模式 |
| 日期差一天 | `TIMEZONE` 是否为 `Asia/Shanghai` |

> 本地开发与冒烟测试见 `README.md` 一节与 `测试流程.md`（`npm run dev`，端口 8787）。
